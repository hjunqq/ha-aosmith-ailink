# HomeKit 与 Siri 使用指南

AO Smith 系统的冷源、热泵和壁挂炉是全屋共享设备。每个房间可以独立开关、设定温度和调节风速，但不能让不同房间同时运行互相冲突的制冷、热泵采暖或壁挂炉采暖模式。

集成会同步所有已开启房间的底层运行模式，同时保留各房间的开关状态和关闭房间原有的模式。选择采暖策略只更新中控热源和正在采暖的房间，不会把正在制冷的房间改成采暖，也不会开启关闭中的房间。

## HomeKit Bridge 配置

建议建立独立的 `AO Smith 温控` HomeKit Bridge，只暴露以下三类实体：

- 每个房间一个 `climate`，例如 `climate.ke_ting`
- 每个房间一个 `fan`，例如 `fan.ke_ting_fan`
- 四个全屋采暖策略开关

四个全屋采暖策略实体为：

| 实体 | 建议 HomeKit 名称 | 作用 |
|---|---|---|
| `switch.ao_smith_whole_home_heating_eco` | 全屋节能双热源 | ECO 双能采暖 |
| `switch.ao_smith_whole_home_heating_max` | 全屋强劲双热源 | Max 双能采暖 |
| `switch.ao_smith_whole_home_heating_boiler` | 全屋壁挂炉 | 仅壁挂炉/地暖 |
| `switch.ao_smith_whole_home_heating_heat_pump` | 全屋热泵 | 仅热泵/风暖 |

这四个开关是互斥策略，打开其中一个即替换当前策略。不要对 Siri 说“关闭全屋壁挂炉”；需要改变热源时应直接打开另一个策略，需要停止采暖时应关闭对应房间温控。

不要向 HomeKit 暴露以下实体：

- 每个房间的制冷、风暖、通风、地暖、双能、除湿模式开关
- `select` 模式选择器
- AO Smith 的传感器和二进制传感器

这些实体继续保留在 Home Assistant 中，供 Dashboard、自动化和诊断使用。

## Siri 口令

以下示例按 HomeKit 配件名称为“客厅温控”“主卧温控”“次卧温控”“书房温控”编写。

### 制冷

制冷口令应同时包含房间、模式和温度：

- “把客厅温控设为制冷 26 度”
- “把主卧温控设为制冷 25 度”
- “把次卧温控设为制冷 26 度”
- “把书房温控设为制冷 25 度”
- “关闭客厅温控”

任一房间切换到制冷时，集成会将全屋底层模式同步为制冷，但只开启口令中指定的房间。如果旧制冷目标温度高于 27°C，集成会自动调整到 26°C，避免沿用采暖温度。

### 采暖

采暖使用两步口令。第一步选择全屋热源，第二步开启需要采暖的房间：

1. 说“打开全屋壁挂炉”“打开全屋热泵”“打开全屋节能双热源”或“打开全屋强劲双热源”。
2. 说“把主卧温控设为制热 22 度”。其他房间按需分别开启。

示例：

- 壁挂炉采暖：“打开全屋壁挂炉”，然后说“把主卧温控设为制热 22 度”
- 热泵采暖：“打开全屋热泵”，然后说“把客厅温控设为制热 23 度”
- 节能双热源：“打开全屋节能双热源”，然后说“把次卧温控设为制热 22 度”
- 停止某个房间采暖：“关闭主卧温控”

选择采暖策略不会自动打开所有房间。正在采暖的房间会同步采用新策略，正在制冷的房间不受影响，关闭的房间仍保持关闭。

### 风速

每个房间的风速配件独立控制。HomeKit 百分比与设备档位的对应关系为：

| Siri 口令 | 设备档位 |
|---|---|
| “把客厅风速设为 25%” | 低 |
| “把客厅风速设为 50%” | 中 |
| “把客厅风速设为 75%” | 高 |
| “把客厅风速设为 100%” | 强劲 |
| “把客厅风速设为自动” | 自动 |

对风速配件说“关闭”会关闭对应房间温控，而不只是把风速降为零。

## 应避免的口令

不要使用含义过宽或缺少房间范围的口令：

- “打开空调”
- “打开制热”
- “把家里调到 22 度”
- “关闭壁挂炉”
- “打开客厅”

这些口令可能被 Siri 匹配到多个配件，或者无法明确选择全屋热源。固定使用“房间名 + 温控 + 模式 + 温度”，可以显著减少误操作。

## 控制逻辑摘要

- 全屋只能存在一种底层冷暖模式。
- 制冷、热泵采暖、壁挂炉采暖和双热源策略互斥。
- 房间开关、目标温度和风速独立。
- 切换全屋策略不会开启原本关闭的房间，也不会把正在制冷的房间改为采暖。
- 普通“打开温控”会沿用当前全屋模式，不会强制切换到制热。
- 停止采暖时关闭房间温控，不要关闭全屋策略开关。
