# HomeKit 与 Siri 使用指南

AO Smith 使用两层控制：第一层是全屋制冷或采暖；第二层仅在采暖时选择 ECO、Max、单壁挂炉或单热泵。每个房间只独立控制开关、温度和风速。

## 安全边界

集成严格复现原 AiLink H5：

- `select.ao_smith_system_mode` 通过客厅主温控切换全屋制冷/采暖
- `select.ao_smith_center_controller_heating_mode` 只在全屋采暖时选择四种采暖方式
- 四个房间不再提供独立冷暖模式选择，只保留开关、温度和风速
- HomeKit 不暴露两个 `select`，避免 Siri 误触采暖方式

全面控制 Dashboard 提供以下安全操作：

- 全屋制冷/采暖和采暖方式两层控制
- 四个房间独立开关、温度和风速控制
- “关闭全屋温控”按钮和 HomeKit 总开关，一次关闭四个房间且不改变两层模式

关闭房间使用温控器自身的 `SetTCU` 电源接口。关闭全屋温控本质上是依次关闭四个房间，不改变全屋模式或采暖方式。

## HomeKit Bridge 配置

独立的 `AO Smith 温控` HomeKit Bridge 只应暴露九个实体：

- 四个房间 `climate`：客厅、主卧、次卧、书房温控
- 四个房间 `fan`：客厅、主卧、次卧、书房风速
- `switch.ao_smith_whole_home_power`：全屋温控总开关

“全屋温控总开关”的关闭动作会逐一关闭四个房间。其开启动作被永久禁用，避免一个模糊口令同时启动多个房间或意外进入采暖。

不要向 HomeKit 暴露：

- 全屋运行模式和中控采暖方式 `select`
- 历史房间级模式开关或选择器
- AO Smith 传感器和二进制传感器

## Siri 口令

以下示例按 HomeKit 配件名称为“客厅温控”“主卧温控”“次卧温控”“书房温控”编写。

### 制冷

口令应同时包含房间、模式和温度：

- “把客厅温控设为制冷 26 度”
- “把主卧温控设为制冷 25 度”
- “把次卧温控设为制冷 26 度”
- “把书房温控设为制冷 25 度”
- “关闭客厅温控”

任一房间显式切换到制冷时，集成通过客厅主温控把全屋模式切为制冷，再开启目标房间；不会逐房间写模式。如果旧制冷目标温度高于 27°C，集成会自动调整到 26°C。

### 采暖

Siri 不选择 ECO、Max、壁挂炉或热泵方式，只使用当前已选定的采暖方式：

- “把主卧温控设为制热 22 度”
- “把客厅温控设为制热 23 度”
- “关闭主卧温控”

明确设置某个房间为制热时，集成先通过客厅主温控把全屋模式切为采暖，再开启目标房间；当前采暖方式保持不变。需要改变采暖方式时，使用 Home Assistant 全面控制 Dashboard、原控制器或官方 App。

普通“打开温控”和关闭状态下的风速口令不会从上次保存的采暖模式启动设备。启动采暖必须明确说“把主卧温控设为制热 22 度”这类包含制热模式的口令。

### 风速

| Siri 口令 | 设备档位 |
|---|---|
| “把客厅风速设为 25%” | 低 |
| “把客厅风速设为 50%” | 中 |
| “把客厅风速设为 75%” | 高 |
| “把客厅风速设为 100%” | 强劲 |
| “把客厅风速设为自动” | 自动 |

对风速配件说“关闭”会关闭对应房间温控，而不只是把风速降为零。

## 停止制热

停止单个房间：

- “关闭客厅温控”
- “关闭主卧温控”
- “关闭次卧温控”
- “关闭书房温控”

停止全屋可以使用任一方式：

- 对 Siri 说“关闭全屋温控总开关”
- 在 Home App 关闭“全屋温控总开关”
- 在 Home Assistant 全面控制 Dashboard 点击“关闭全屋温控”并确认

这些入口都只关闭四个温控器，不下发采暖策略。“全屋温控总开关”不能用于开启全屋设备。

## 应避免的口令

- “打开空调”
- “打开制热”
- “打开全屋壁挂炉”
- “打开全屋热泵”
- “关闭壁挂炉”
- “把家里调到 22 度”

固定使用“房间名 + 温控 + 模式 + 温度”，可以减少 Siri 匹配多个配件造成的误操作。
