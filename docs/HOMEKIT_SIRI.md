# HomeKit 与 Siri 使用指南

AO Smith 系统的冷源、热源和中控策略是全屋共享资源。每个房间可以独立开关、设定温度和调节风速，但正在运行的房间不能采用互相冲突的制冷与制热模式。

## 安全边界

Home Assistant 只读取中控器当前采暖策略，不提供修改策略的实体，也不会调用 `HeatingModeSet`。壁挂炉、热泵、ECO 或 Max 策略应通过原控制器或官方 App 管理。

全面控制 Dashboard 提供以下安全操作：

- 四个房间独立开关、模式、温度和风速控制
- 当前中控采暖策略只读显示
- “关闭全屋温控”按钮，一次关闭四个房间且不修改中控采暖策略

关闭房间使用温控器自身的 `SetTCU` 电源接口。关闭全屋温控本质上是依次关闭四个房间，不会向中控下发采暖策略。

## HomeKit Bridge 配置

独立的 `AO Smith 温控` HomeKit Bridge 只应暴露八个实体：

- 四个房间 `climate`：客厅、主卧、次卧、书房温控
- 四个房间 `fan`：客厅、主卧、次卧、书房风速

不要向 HomeKit 暴露：

- 中控采暖策略
- 每个房间的制冷、风暖、通风、地暖、双能、除湿模式开关
- `select` 模式选择器
- AO Smith 传感器和二进制传感器

## Siri 口令

以下示例按 HomeKit 配件名称为“客厅温控”“主卧温控”“次卧温控”“书房温控”编写。

### 制冷

口令应同时包含房间、模式和温度：

- “把客厅温控设为制冷 26 度”
- “把主卧温控设为制冷 25 度”
- “把次卧温控设为制冷 26 度”
- “把书房温控设为制冷 25 度”
- “关闭客厅温控”

任一房间显式切换到制冷时，集成只同步当前已开启的房间和目标房间；关闭中的房间保持原状。如果旧制冷目标温度高于 27°C，集成会自动调整到 26°C，避免沿用采暖温度。

### 采暖

Siri 不选择壁挂炉、热泵、ECO 或 Max 策略，只使用原控制器当前已经选定的策略：

- “把主卧温控设为制热 22 度”
- “把客厅温控设为制热 23 度”
- “关闭主卧温控”

需要改变采暖来源时，应使用原控制器或官方 App；不要通过 HomeKit 或 Siri 修改中控策略。

### 风速

| Siri 口令 | 设备档位 |
|---|---|
| “把客厅风速设为 25%” | 低 |
| “把客厅风速设为 50%” | 中 |
| “把客厅风速设为 75%” | 高 |
| “把客厅风速设为 100%” | 强劲 |
| “把客厅风速设为自动” | 自动 |

对风速配件说“关闭”会关闭对应房间温控，而不只是把风速降为零。

## 停止制热

停止单个房间：

- “关闭客厅温控”
- “关闭主卧温控”
- “关闭次卧温控”
- “关闭书房温控”

停止全屋时，在 Home Assistant 全面控制 Dashboard 点击“关闭全屋温控”并确认。该按钮只关闭四个温控器，不下发采暖策略。

## 应避免的口令

- “打开空调”
- “打开制热”
- “打开全屋壁挂炉”
- “打开全屋热泵”
- “关闭壁挂炉”
- “把家里调到 22 度”

固定使用“房间名 + 温控 + 模式 + 温度”，可以减少 Siri 匹配多个配件造成的误操作。
