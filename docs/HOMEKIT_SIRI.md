# HomeKit 与 Siri 使用指南

## 全屋总控

在 HA 仪表盘用「全屋运行模式」选择停机、制冷或采暖。冷暖切换先关闭房间，再等待壁挂炉和热泵回报空闲。确认失败时，HA 保持房间启动锁定并报错。遇到设备不提供所需状态时，可以在原厂中控完成切换，再在 HA 确认已选中的模式。

只在全屋采暖时可修改中控热源策略。房间的地暖和风暖则是各自温控器的预设。关闭全屋温控会关闭所有房间并锁定房间启动，恢复运行时在 HA 总控明确选择制冷或采暖。

## Siri 口令

以下示例以主卧为例。客厅、次卧和书房使用相同格式。

| 口令 | 动作 |
|---|---|
| “打开主卧舒适模式” | 沿用全屋制冷或采暖。默认选择制冷 26°C 或采暖 22°C |
| “打开主卧切到地暖” | 选择主卧地暖 |
| “打开主卧切到风暖” | 选择主卧风暖 |
| “把主卧温控调到 25 度” | 调整主卧目标温度 |
| “关闭主卧温控” | 关闭主卧 |
| “关闭全屋温控总开关” | 停止全屋 |

切换散热方式只在采暖期间有效。房间已开启时直接切换；房间关闭时记住偏好，下次开启时应用。热源继续由中控决定。制冷时，房间的制热指令和采暖预设都在 HA 中被拒绝。调风速前先开启房间；关闭风速配件会关闭对应房间。

## HomeKit Bridge 配置

将 [房间脚本示例](examples/aosmith_homekit_room_scripts.yaml) 合并到 HA 的 `scripts.yaml`。桥接房间温控、风速、`switch.ao_smith_whole_home_power`，以及按房间命名的舒适模式、地暖和风暖脚本。辅助脚本 `script.ao_smith_room_comfort` 留在 HA。脚本显示为瞬时开关，执行后会回到关闭状态。

从桥接白名单移除旧的 `script.ao_smith_homekit_floor_heat`、`script.ao_smith_homekit_warm_air` 和 `script.ao_smith_homekit_max_heat`。全屋模式与热源选择留在 HA。
